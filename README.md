# VEX V5 Robotics - Addis Ababa University

## 📌 Overview
Welcome to the **VEX V5 Robotics** repository of Addis Ababa University! This repository contains code for different autonomous modes and driving skills used in VEX Robotics competitions. We are currently using **VEXcode Blocks** to develop and implement our programs.

## 📂 Repository Structure
This repository includes the following code modules:

### 🔹 Autonomous Modes
- **RedLeft** - Autonomous code for the red alliance starting from the left side.
- **RedRight** - Autonomous code for the red alliance starting from the right side.
- **BlueLeft** - Autonomous code for the blue alliance starting from the left side.
- **BlueRight** - Autonomous code for the blue alliance starting from the right side.

### 🔹 Skills Challenge
- **AutonomousSkills** - Code for the autonomous skills challenge.
- **DrivingSkills** - Code for the driving skills challenge.

## 🛠 Requirements
- **VEX V5 Robot Brain**
- **VEXcode Blocks (or equivalent IDE for VEX programming)**
- **VEX Sensors and Motors** (as required by the robot design)

## 🚀 Getting Started
1. Clone the repository using the following command:
   ```bash
   git clone https://github.com/your-repo-link/vex-v5-robotics.git
   ```
2. Open **VEXcode Blocks** and import the respective program file.
3. Deploy the code to your **VEX V5 Brain**.
4. Test the autonomous and driving skills programs on the field.

## 📜 Code Implementation
Each autonomous mode follows a structured approach:
1. **Initialization:** Configure motors, sensors, and other components.
2. **Preload Actions:** Handle any preload elements before movement.
3. **Main Autonomous Path:** Navigate, pick up, or manipulate game elements based on strategy.
4. **End Conditions:** Ensure the robot is in a final stable state before tele-op begins.
